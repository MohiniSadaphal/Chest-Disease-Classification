# Chest-Disease-Classification
# 🫁 End-to-End Chest Disease Classification

A deep learning project that automatically classifies chest diseases from medical imaging data — making diagnostics faster, smarter, and more accessible.

---

## 🔍 About the Project

Medical imaging plays a huge role in detecting chest diseases, but manual interpretation by radiologists is time-consuming and prone to delays. This project builds an end-to-end deep learning pipeline that automatically classifies chest conditions from imaging data — helping bridge the gap between technology and healthcare.

The goal was to create a reliable, automated system that could assist in early and accurate detection of chest diseases.

## 🚀 How to Run Locally



1. **Clone the repository**
   ```bash
   git clone https://github.com/MohiniSadaphal/End-to-End-Chest-Disease-Classification.git
   cd End-to-End-Chest-Disease-Classification
   ```

2. **Create and activate a virtual environment**
   ```bash
   conda create -p <Environment_Name> python==<python_version> -y
   conda activate <Environment_Name>/
   ```

3. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the app**
   ```bash
   python app.py
   ```

5. Open your browser and access the project locally.
